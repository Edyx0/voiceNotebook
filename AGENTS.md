# Design guidance

Use https://developer.apple.com/design/ and the relevant detailed Apple Human Interface Guidelines for all interface work. For this Mac app, apply macOS window/menu conventions, familiar controls, keyboard navigation, accessible labels and clear feedback. Keep the interface very simple. Preserve the voiceNotebook wordmark and the user's supplied palette and 80s industrial direction.

Weekly timetables must support photo recognition with editable results. Recognition happens locally on the Mac; review and save are explicit before the timetable changes. Never invent unreadable lecture times.

Preserve unrelated work. Commit and push completed coherent owned changes when a remote is configured.
