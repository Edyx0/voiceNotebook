# voiceNotebook 0.1.1

Refines the toolbar's photo action with a centered photo symbol and removes the protruding plus sign. The accessible label and photo-selection flow remain available.

```sh
brew install --cask edyx0/tap/voicenotebook
```

Existing Homebrew installations can run:

```sh
brew update
brew upgrade --cask edyx0/tap/voicenotebook
```

Apple silicon, macOS Tahoe 26 or newer. Homebrew installs FFmpeg; Python is bundled. The app is Developer ID signed and Apple notarized, with a stapled ticket. See the README for permissions and the unofficial NotebookLM integration's limitations.
